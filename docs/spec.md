# 窗口缩放器规格

用户于2026-11-08确认实施。任务进度以 [GitHub Issues](https://github.com/Capsule7446/window-scaler/issues) 为准。

## 范围

独立Windows应用，采用Rust + GPUI Kit。提供窗口选择、本体缩小、系统最大化、目标窗口隐藏与显示，以及系统托盘；不包含游戏启动、多开、自动按键、资源优化或镜像预览。

## 窗口选择

- 列出普通桌面应用窗口，包括最小化窗口；排除本工具、桌面、任务栏及系统辅助窗口。
- 展示标题、程序名、PID、当前内容区尺寸和操作结果。读取不到程序名时仍保留窗口条目。
- 按标题、程序名或PID进行不区分大小写的包含搜索。提供刷新和清空勾选。
- 支持单选或多选。过滤保留勾选；显示已选总数与隐藏的已选数量，按钮操作全部已选项。
- 打开主界面时刷新，后台托盘状态不持续刷新列表。窗口关闭或身份失效时移除对应选择；句柄或PID复用不得继承原窗口的选择与退出记录。

## 界面布局

用户于 2026-11-08 选择 B 双栏操作台，以多窗口批量管理为主。

- 左侧提供搜索、刷新、清空勾选和窗口列表；每行展示标题、程序、PID、内容区尺寸、隐藏状态及操作结果。长标题可悬停查看，操作失败详情保留在行内。
- “全选当前列表”只增减当前搜索结果中的可操作窗口，保留筛选外的勾选项，跳过不可操作窗口；部分选中时显示半选状态。
- 右侧持续显示已选总数、所选窗口摘要及筛选外的已选数量，按窗口大小和窗口可见性分区操作。
- 底部显示操作状态和“正常退出”；退出失败显示可滚动的失败列表，以及重试和仍然退出入口。托盘行为与原有退出恢复规则一致。
- 默认窗口为 960×680，最小内容区为 760×540。列表与右侧面板独立滚动，缩小界面不会横向裁切操作按钮。

## 缩小与放大

- 目标宽度为内容区的屏幕像素宽度，默认240。只接受有效正整数，点击按钮才修改目标窗口。
- 同一窗口在本次运行中使用第一次缩小前的有效宽高比；重复缩小或放大后再缩小不累积取整误差。最小化窗口先恢复显示再取得尺寸。
- 计算结果无效、溢出或完整窗口超过所在显示器工作区时显示错误。尺寸尽量保留原位置，必要时移回所在显示器工作区。
- 放大优先使用目标窗口的系统最大化命令，并核对实际几何；仅有最大化状态标志不能算成功。
- 用户在2026-11-08补充确认：系统最大化未实际放大时，回退到本次运行中该窗口第一次缩小前的内容区尺寸。回退成功显示“已恢复原尺寸”；没有原尺寸记录或恢复失败时报告错误。
- 各窗口独立处理，单个失败不阻断其他目标。读取实际尺寸或最大化状态确认结果，不能把API受理直接视为成功。
- 同一窗口的操作顺序执行；已提交但结果未确认的请求必须保留，后续操作不能绕过未完成请求。

## 托盘与退出

- 启动显示主界面；主界面×隐藏工具，不改变目标窗口。托盘左键单击打开界面，右键菜单提供显示主界面及退出。
- 托盘创建失败时保持主界面可见，提供备用退出入口；×不能把工具隐藏到无法恢复的状态。
- 正常退出先放大本次运行中由本工具缩过且仍为同一实例的窗口，不受当前勾选和搜索影响；同样允许原尺寸回退。已关闭的目标跳过。
- 用户确认：正常退出先显示本次运行中由本工具隐藏且仍为同一实例的窗口，再执行上述退出放大规则；仅隐藏过的窗口保持隐藏前的大小和位置。显示失败或结果无法确认时纳入退出失败列表。
- 退出开始后不接受新的缩小；已提交请求须先完成。超时或无法确认结果时列为退出失败，不能宣布全部完成。
- 退出放大失败时显示失败列表，并提供重试放大并退出、仍然退出。强制结束、崩溃和系统关机不保证放大完成。

## 目标窗口隐藏与显示

- 用户确认：隐藏直接令目标窗口不可见，不执行最小化、不结束目标进程；通过本工具内的“显示”按钮恢复。
- “隐藏”“显示”操作全部已选窗口，包括被搜索过滤的勾选项。被本工具隐藏的窗口继续保留在列表，标记“已隐藏”，刷新和打开主界面后仍可选择并显示。
- 用户确认：手动显示保持隐藏前的大小和位置，并保留原来的普通、最大化或最小化状态；“显示”不等同于“放大”。对已显示窗口重复显示不改变其大小或位置。
- 目标自行重新显示后，“显示”保留其当前位置和大小，清除对应隐藏记录；此前显示失败且仍需恢复位置或状态的记录继续保留，供重试。
- 隐藏记录按窗口实例保存，重复隐藏不覆盖首次隐藏前的状态；已关闭或身份失效的窗口不恢复、不把记录转移给复用句柄的窗口。不把其他程序自行隐藏的窗口纳入管理。
- 隐藏状态下若要缩小或放大，先显示，再执行对应操作；同一窗口的请求继续串行，未确认请求不得被后续操作绕过。操作结果核对实际可见性和位置大小，单个失败不阻断其他目标。
- 隐藏不承诺目标程序继续渲染或保持后台运行速度。强制结束本工具、崩溃和系统关机不保证自动显示；显示记录不跨工具重启保存。

## 设置与兼容

- 只保存有效目标宽度；首次启动或设置损坏时使用240。重开清空搜索和勾选，不持久化窗口身份。
- 程序内保留比例和退出放大记录；空闲时避免持续重绘或高频轮询。
- 目标软件自行决定缩小后的内容显示，可能重排或裁切。不承诺所有软件完整等比显示，也不改变目标软件内部鼠标坐标。

## 验收

1. Windows锁定依赖构建成功，主界面和托盘共存，隐藏后可从托盘恢复。
2. 单选、多选、搜索和隐藏勾选计数符合上述规则；失效窗口不会转移选择。
3. 缩小改变同一原窗口；240像素宽度及重复缩放比例正确。真实游戏观察与普通测试窗口结果分别记录。
4. 系统最大化、先最大化后最小化、多显示器与不同DPI分别验证；单个拒绝或超时不阻断其他目标。
5. 正常退出放大所有本次缩过的存活目标，包括未勾选或被过滤隐藏的目标；失败分支可重试或明确仍然退出。
6. 单选与多选隐藏后，目标不可见且最小化状态不因隐藏改变；刷新后仍可从列表显示，普通与最大化窗口的位置和大小保持。正常退出显示所有本次隐藏的存活目标，只有缩小过的目标再执行放大；关闭、复用和未确认请求不得误恢复或提前宣告完成。
