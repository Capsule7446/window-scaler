# 窗口缩放器规格

用户于2026-11-08确认实施。任务进度以 [GitHub Issues](https://github.com/Capsule7446/window-scaler/issues) 为准。

## 范围

独立Windows应用，采用Rust + GPUI Kit。提供窗口选择、本体缩小、系统最大化与系统托盘；不包含游戏启动、多开、自动按键、资源优化或镜像预览。

## 窗口选择

- 列出普通桌面应用窗口，包括最小化窗口；排除本工具、桌面、任务栏及系统辅助窗口。
- 展示标题、程序名、PID、当前内容区尺寸和操作结果。读取不到程序名时仍保留窗口条目。
- 按标题、程序名或PID进行不区分大小写的包含搜索。提供刷新和清空勾选。
- 支持单选或多选。过滤保留勾选；显示已选总数与隐藏的已选数量，按钮操作全部已选项。
- 打开主界面时刷新，后台托盘状态不持续刷新列表。窗口关闭或身份失效时移除对应选择；句柄或PID复用不得继承原窗口的选择与退出记录。

## 缩小与放大

- 目标宽度为内容区的屏幕像素宽度，默认240。只接受有效正整数，点击按钮才修改目标窗口。
- 同一窗口在本次运行中使用第一次缩小前的有效宽高比；重复缩小或放大后再缩小不累积取整误差。最小化窗口先恢复显示再取得尺寸。
- 计算结果无效、溢出或完整窗口超过所在显示器工作区时显示错误。尺寸尽量保留原位置，必要时移回所在显示器工作区。
- 放大等同于系统最大化，不恢复历史尺寸；目标不接受最大化时显示失败。
- 各窗口独立处理，单个失败不阻断其他目标。读取实际尺寸或最大化状态确认结果，不能把API受理直接视为成功。
- 同一窗口的操作顺序执行；已提交但结果未确认的请求必须保留，后续操作不能绕过未完成请求。

## 托盘与退出

- 启动显示主界面；主界面×隐藏工具，不改变目标窗口。托盘左键单击打开界面，右键菜单提供显示主界面及退出。
- 托盘创建失败时保持主界面可见，提供备用退出入口；×不能把工具隐藏到无法恢复的状态。
- 正常退出先放大本次运行中由本工具缩过且仍为同一实例的窗口，不受当前勾选和搜索影响。已关闭的目标跳过。
- 退出开始后不接受新的缩小；已提交请求须先完成。超时或无法确认结果时列为退出失败，不能宣布全部完成。
- 退出放大失败时显示失败列表，并提供重试放大并退出、仍然退出。强制结束、崩溃和系统关机不保证放大完成。

## 设置与兼容

- 只保存有效目标宽度；首次启动或设置损坏时使用240。重开清空搜索和勾选，不持久化窗口身份。
- 程序内保留比例和退出放大记录；空闲时避免持续重绘或高频轮询。
- 目标软件自行决定缩小后的内容显示，可能重排或裁切。不承诺所有软件完整等比显示，也不改变目标软件内部鼠标坐标。

## 验收

1. Windows锁定依赖构建成功，主界面和托盘共存，隐藏后可从托盘恢复。
2. 单选、多选、搜索和隐藏勾选计数符合上述规则；失效窗口不会转移选择。
3. 缩小改变同一原窗口；240像素宽度及重复缩放比例正确。真实游戏观察与普通测试窗口结果分别记录。
4. 系统最大化、先最大化后最小化、多显示器与不同DPI分别验证；单个拒绝或超时不阻断其他目标。
5. 正常退出放大所有本次缩过的存活目标，包括未勾选或被过滤隐藏的目标；失败分支可重试或明确仍然退出。
